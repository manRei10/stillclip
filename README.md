## Key Features

1. **Apple Vision Neural Engine OCR (`VNRecognizeTextRequest`)**:
   Automatically extracts Japanese & English text from any copied screenshot (`⌘⇧⌃4`) 100% offline. Press `⌥↵` to paste the recognized text directly.
2. **Smart Clean Paste (`⌥↵`)**:
   Joins broken hyphenated words from two-column academic PDFs, strips `utm_*` / `fbclid` tracking parameters from URLs, and pretty-prints single-line JSON.
3. **Sequential Paste Stack (`⌘Q`)**:
   Copy 1, 2, 3 in sequence and paste them in exact FIFO order without switching windows.
4. **Zero Shortcut Conflict (`Double ⌘C`)**:
   Summon the palette by tapping `⌘C` twice quickly (or `⌥⌥` / `⌘⇧V`).
