02 · SMART CLEAN PASTE (⌥↵) PDF · URL · JSON

論文PDFのハイフン改行とURLの追跡タグを0.01秒で浄化

2段組PDFからコピーした際の途切れた英単語（in-\nformation）や不要な改行の結合、URLの utm_* / fbclid 除去、1行JSONの整形を、ペースト時の ⌥↵ キーひとつで完結させます。

03 · SEQUENTIAL PASTE STACK (⌘Q) FIFO Queue Mode

「1, 2, 3と連続コピーして、順番通りに貼り付ける」FIFOキュー

ウィンドウを行き来する転記作業をなくす Paste Stack モードを搭載。コピーした順番にキューへ積み上げ、ターゲット画面で順番通りに流し込めます。

04 · ZERO SHORTCUT CONFLICT CGEventTap Double ⌘C

既存アプリのショートカットを一切奪わない「ダブル ⌘C」起動

CoreGraphics の Listen-Only Event Tap により、毎日使う ⌘C を素早く2回叩くだけ（または ⌥⌥ / ⌘⇧V）で起動。直前のアクティブウィンドウへフォーカスを戻して ⌘V を自動注入します。
